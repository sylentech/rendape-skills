# rendape-skills

Skills do Claude Code compartilhadas da Rendápê.

Aqui ficam as skills da equipe (sites, vídeo e o que mais surgir), cada uma na sua pasta.

## Como usar

Clone o repositório e copie as pastas de `skills/` para `~/.claude/skills/`:

```bash
git clone https://github.com/sylentech/rendape-skills.git
cp -r rendape-skills/skills/* ~/.claude/skills/
```

Cada skill vive em `skills/<nome>/SKILL.md`.

## Skills de sites

- **abertura-de-marca** — intro animada da logo na primeira visita de um site (CSS puro, sem JS de animação).
- **site-animado-3d** — padrão de site institucional animado: cenas 3D em vídeo, entradas na rolagem e títulos palavra por palavra.
